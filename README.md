# 🚚 Mudanzas GL

Sistema web completo para la gestión de una empresa de mudanzas.

## 📋 Descripción

Sistema de información desarrollado en PHP + MySQL para gestionar todo el flujo de una empresa de mudanzas: desde la cotización inicial hasta la calificación del servicio.

## ✨ Funcionalidades

- 🔐 **Autenticación con 3 roles**: cliente, colaborador y administrador
- 💰 **Cotización** con API externa de ciudades de Colombia
- 📅 **Agendamiento** de mudanzas con fecha, hora y direcciones
- 💳 **Sistema de pagos** con 5 métodos (efectivo, transferencia, tarjeta, nequi, daviplata)
- 💵 **Comisiones automáticas** (15% empresa / 85% colaborador)
- ⭐ **Calificaciones** con estrellas y ranking de colaboradores
- 📸 **Galería de fotos** por mudanza (antes/durante/después)
- 🔔 **Notificaciones** en tiempo real
- 🗺️ **Mapa interactivo** con ubicación de la empresa

## 🛠️ Tecnologías

- **Backend:** PHP 8 + PDO
- **Base de datos:** MySQL
- **Frontend:** HTML5, CSS3, JavaScript (Vanilla)
- **Mapas:** Leaflet + OpenStreetMap
- **API externa:** api-colombia.com
- **Servidor:** XAMPP (Apache)
